# 实验4与实验5：十项改进的分领域结果

**10/10项正式实验已完成，全部原始排名或预测通过审计。** 按用户本轮允许局部提升的目标，最值得保留的是实验4的旧图库部分白化，以及实验5的候选分布加权岭回归：前者在Oxford/Holidays改善、在Paris退步；后者在EuroSAT同域明显改善、在部分跨域条件退步。桥接集成和候选方差校正另有稳定但较小的局部收益。

这批结果支持保留分领域版本，不支持统一替换所有任务的默认方法。公式本身的新颖性不是本轮已证明的结论。候选动机、机制、反对解释和9篇相关工作见[十项预案](../ideas.md)，固定配方见[candidates.json](../candidates.json)。

## 实际执行与比较方式

- 正式顺序：五项研究4，随后五项研究5，52服务器物理GPU2/4CPU线程，未在53运行GPU实验。正式控制器从2026-09-09 21:08:37运行至21:24:33（北京时间），全部退出码0。读取旧特征与小矩阵处理使用CPU，图库图构建和分类批次使用GPU；没有新增图像编码或编码器训练。
- 研究4：每项180个对齐比较单元，共900个新排名文件，覆盖Oxford/Paris/Holidays、两编码器对、32/64桥接、五种子和三种桥接策略。排名文件合计192000条查询排名；相同图像重复用于不同方法和设置，不是192000张独立查询。
- 研究5：四项1-shot和一项5-shot，每项10条件×5种子×600题=30000题，共150000次候选题评估；另加30000题普通集成归因对照。多方法共享同一题，不能等同于180000道独立题。
- 研究4的主表对照是各条件此前最强的九种原基线、纯中心化和上一轮alpha2方案；另与本轮白化对照核对。研究5同时比较R2及同特征/同lambda纯支持读出。
- 子领域按既定数据集、编码器、桥接预算/来源和难度定义。配置在生成本轮分数前冻结，但这些图像池此前已查看，结论属于探索性分域复测，不是新数据独立确认。

## 实验4：哪些区域真的变好

### 旧图库部分白化的完整几何结果

仅使用旧图库特征估计均值与协方差，收缩量为0.1×平均特征方差，谱变换指数为−1/4，再归一化。相比全白化更温和，但仍会提高低方差方向的相对权重。这是旧空间几何改进，不是恢复了新编码器的缺失信息。

|数据集|旧编码器|难度|纯中心化|部分白化|增益［95%区间］|
|---|---|---|---:|---:|---:|
|Holidays|clip_b16|map|87.613|90.082|+2.468［+1.428,+3.571］|
|Holidays|clip_b32|map|85.673|87.998|+2.325［+1.147,+3.617］|
|Oxford|clip_b16|medium|27.895|31.913|+4.018［+2.005,+6.457］|
|Oxford|clip_b16|hard|6.447|7.560|+1.113［+0.363,+2.072］|
|Oxford|clip_b32|medium|26.056|27.973|+1.917［-0.350,+4.048］|
|Oxford|clip_b32|hard|6.909|8.104|+1.195［+0.241,+2.232］|
|Paris|clip_b16|medium|69.878|68.460|-1.417［-2.690,-0.148］|
|Paris|clip_b16|hard|47.124|45.294|-1.830［-3.719,-0.091］|
|Paris|clip_b32|medium|63.823|62.477|-1.347［-2.555,-0.269］|
|Paris|clip_b32|hard|40.692|38.808|-1.884［-3.666,-0.332］|

Oxford B16 Medium相对纯中心化提高4.018pp；即使与此前CUB桥接条件下的最强alpha2比较，32/64桥接下仍分别高3.109/3.052pp。Holidays两旧编码器也均提高超过2pp。Paris则四个编码器/难度组合全部下降，幅度约1.3–1.9pp。因此建议作为Oxford/Holidays一类条件的候选几何版本保留，不能对所有地标或所有新数据自动启用。

一种可能解释是旧空间的高方差方向在不同数据域中承载了不同信息：在一些域是干扰，在另一些域可能有判别价值。当前实验只证明收益的领域差异，没有完成主成分语义归因，不能把这种解释写成已证实的因果机制。

### 残差方法的局部边界

桥接集成在Paris、64地标随机、Medium相对此前最强对照提高0.577pp，五种子增益为0.232/1.178/0.871/0.162/0.443pp。它是小幅且可复现的当前图像池内增强，值得保留。与此相伴，它在Oxford、64地标随机、Hard相对此前最强对照下降2.623pp。减少子集分歧并不保证残差没有共同偏差。

图扩散在Oxford Hard的最大平均收益由少数种子拉高：该代表设置的五种子增益约−0.431/+5.881/+2.243/+0.310/−2.069pp。它说明旧图结构可能有用，也说明桥接依赖明显；当前不能把+1.187pp描述成稳定增强。

高斯秩残差未稳定超过旧强对照；仅限制top100也没有大收益。相对在Paris退步的白化，某些残差方案会高出2–3pp，但这不能取代与原先强对照的比较。[与白化的全部配对比较](comparison_whitening.json)单独保留，避免选择较弱对照制造改善。

## 实验5：EuroSAT的局部增强最明确

### 分布读出的收益与代价

每类仍只检索原top64，从中按固定等距rank取16个真实候选，保留每个候选的特征与伪标签；真实支持权重为1，每类伪支持总权重为1。带截距加权岭回归使用同一lambda=0.1。编码器、真实标签数和图库权限不变，但读出计算增加。

|条件|R2|分布读出|增益［95%区间］|
|---|---:|---:|---:|
|CIFAR-FS / cifar100图库|91.520|92.158|+0.637［+0.554,+0.724］|
|DTD / DTD图库|77.251|76.873|-0.378［-0.528,-0.223］|
|miniImageNet / miniImageNet图库|95.018|92.620|-2.398［-2.509,-2.296］|
|DTD / miniImageNet图库|72.944|69.822|-3.121［-3.269,-2.973］|
|CUB / CUB图库|96.383|96.392|+0.008［-0.058,+0.077］|
|EuroSAT / EuroSAT图库|71.528|73.489|+1.961［+1.856,+2.079］|
|CUB / miniImageNet图库|94.560|93.773|-0.787［-0.873,-0.699］|
|EuroSAT / miniImageNet图库|64.805|65.093|+0.288［+0.156,+0.420］|
|Flowers / Flowers图库|99.403|99.101|-0.302［-0.352,-0.253］|
|Flowers / miniImageNet图库|99.219|98.937|-0.282［-0.329,-0.237］|

EuroSAT同域由71.528%提高至73.489%，五种子均提升1.84–2.05pp，相对同特征纯支持读出高6.148pp。CIFAR-FS同域也提高0.637pp，是预期重点之外的探索性小幅收益。DTD跨域下降3.121pp、miniImageNet同域下降2.398pp，全部10条件宏平均反而下降0.437pp。按照本轮的分领域目标，这不否定EuroSAT增强，但明确限制它的部署范围。

该结果支持保留“候选作为多个训练点”的整体读出方案；尚未单独证明类内多模态就是因果原因，收益也可能受有效样本数与正则化尺度变化影响。跨域负结果与伪标签错误被更强读出放大的解释相符，但需要候选正确率诊断才能进一步确认。

### 其余候选的保留价值

候选类内方差校正在EuroSAT同域/跨域相对R2分别提高0.524/0.542pp，CIFAR-FS提高0.284pp；10条件宏平均提高0.148pp。它比大幅分布读出温和，但在Flowers有小幅退步。EuroSAT跨域相对纯支持仍低1.993pp，因此不能解释为跨域图库已经有益。

双编码器一致筛选在CUB/Flowers同域约提高0.069pp，整体下降0.337pp；几何中位数在EuroSAT同域提高0.097pp，整体下降0.017pp。两者说明这些机制有很小的局部信号，但当前收益不足以支持增加较多复杂度。

5-shot支持集校准在EuroSAT提高0.183pp，10条件平均提高0.043pp。预先约定的归因对照发现，固定均匀集成在EuroSAT提高0.208pp，校准反而低0.025pp，区间约［−0.049,−0.001］。DTD校准比均匀集成略好，但只是回到R2水平，没有净增益。应把这条结果主要归为普通预测集成的小幅收益，而非已经学会可靠选择编码器。[完整归因对照](cv_uniform_control/summary.json)。

5-shot方法不使用图库；同查询域在两个图库条件下的结果完全相同，不能当作两份独立验证。

## 资源、完整性与局限

6项契约测试通过：查询/episode与类顺序独立性、零残差、桥接顺序、图权重、top100边界、加权岭与原始空间解一致及复制质量不变性、留一风险与显式重新拟合对拍。研究4逐完整排名重算AP；研究5逐预测重算准确率并核对支持/查询/类别/种子。正式R2重放最大分数误差0、预测翻转0，研究4父基线重放mAP误差0。

实验4全部方法共900个排名文件、实验5共250个候选预测文件，以及50个补充对照文件均已核验。源代码与配方指纹、父输入哈希、运行顺序和完成标记均保留。[最终审计](audit.json)。

运行时间是完整候选作业时间，包含基线对拍、存储和部分预处理，不等同于部署查询延迟。几何白化有旧图库协方差预处理成本；图扩散有旧图库图成本；桥接集成多次复用同一桥接预算；一致性筛选另做两次单编码器近邻搜索；分布读出的矩阵更大；支持集CV多拟合几个小读出。没有证明这些增强免费或更快。

所有结果来自已查看固定图像池；Oxford/Paris同地标查询存在相关性，当前区间按查询图和桥接种子计算，未做地标簇级独立确认；Holidays按500场景配对。研究5区间是固定池内配对episode估计，多条件、多候选筛选未做总体多重检验校正。支持分域候选保留，不等价于已经证明未见域的泛化。
