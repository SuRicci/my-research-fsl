# Active node: baseline verification

目标：从已有原始证据接受一个可用于后续改进的可信对照。
证据：用户指定的实验4/5报告、实现、protocol、逐种子/逐题结果与本机缓存。
约束：不访问远程服务器、不改变查询/训练权限；历史开发池只标记为探索性；论文方法与本地替代分列。
候选：A 复核本地R2（优先，更贴近FSL、已有缓存）；B V0（若A有不可修复缺口）；C 从头复现原论文（现阶段成本较高、仅在不可替代风险时采用）。
效率：先元数据与小型原始结果、复用特征和现有环境，再必要的同协议回放。
成功：代码/数据/协议/结果来源完整，指标可重算，metric_contract.json和confirm_baseline记录存在。
降级：缺失原始证据或不可比时不认定复现；先本机查找合法现存资产，仍不足则decision。
任务：清点与信任分级 -> 重算和必要回放 -> 接受对照 -> idea。
