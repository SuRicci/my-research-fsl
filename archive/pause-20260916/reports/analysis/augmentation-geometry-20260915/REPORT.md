# 增强几何与角色视图对照：已验证结果

## 结论

1. EuroSAT 的收益确实包含无图库的方向效应：真实支持增强方向优于不变换、等谱随机方向和其他任务方向。DTD 没有确立相对不变换的提升。
2. 其他任务方向已经带来较大收益，当前任务方向只进一步增加约 0.38—0.41 个百分点；因此不能把全部收益归因于当前任务特有的信息。
3. EuroSAT 上没有确立连续收缩对硬投影的准确率优势。区间跨零不等于证明两者等价；该结果不支持继续以更复杂的收缩公式作为主要贡献。
4. 支持六视图、查询一视图未达到预设精度保持要求。全六视图固定融合继续作为研发参照；查询端的多视图平均仍有实际作用。

## 1. 单样本角色对照

每域 500 个配对任务，每任务 5 类、每类 15 个查询。两个图库条件先在任务内取平均；图库保持六视图。固定融合是原始与支持中心化散度头的等权分数平均；支持单视图时散度严格为零。表中为准确率百分比。

支持六/查询一相对全六：DTD −0.6360 个百分点，95% 配对区间 [−0.7640, −0.5080]；EuroSAT −1.5467，[−1.7574, −1.3360]。两域均未通过预先固定的区间下界不低于 −0.5 的要求。

理论在线编码视图数减少 78.125%，但图库预编码、预处理和分类器成本不在该比例内，也没有实际端到端耗时测量。

同预算的几何增量：EuroSAT 在支持六/查询一时相对均值固定融合增加 4.1613 个百分点 [3.7839, 4.5467]，全六时增加 3.4613 [3.1187, 3.8080]；DTD 分别仅增加 0.0307 和 0.1013，区间均跨零。单样本几何还会改变图库评分与邻居，因此其图库无关解释依赖下表。

## 3. 机制解释与下一步

支持的解释：EuroSAT 的增强子空间方向包含有用信息，任意等谱方向不能复现提升；同域的任务间共享方向可能解释相当部分收益，当前支持方向仍有额外增量。这里的共享结构只是待检验解释，不是已证明的数据生成机制。

变换不等价：EuroSAT ridge 中真实收缩相对硬投影纠正 611、破坏 599 个查询；logistic 中纠正 545、破坏 586 个。相近平均准确率并不表示分数、预测或抑制的有效强度完全相同。

下一步优先用当前保存特征做一次解释性检查：真实/随机/其他任务子空间分别捕获多少独立查询图像的类内变化和类间差异，并检查这种差别与逐任务净收益的关系。查询标签仅用于事后机制诊断，不能进入推断选择；这不会产生新的独立验证结论。先得到可检验的适用条件，再冻结规则并安排未参与选择的新域确认。图库组成主线暂缓；不重开旧路由、小网络或参数网格。

## 4. 验证、成本与证据边界

- 16 份原始/多视图特征按历史 SHA256 和图像身份恢复。单样本历史预测：1000 个唯一任务、6000 个头/图库任务比较完全一致；保留的抽样分数误差为零。五样本历史对应端点同样通过独立于角色条件的桥接检查。
- 18 份新数组全量检查：分数有限、预测与 argmax 一致、任务配对、支持/查询不重叠、单视图权限、其他任务类别排除和均值/差值算术均通过。
- 90 项预先选定的任务/设置抽样评分检查通过；最大分数误差 3.3029134982598407e-15，预测差异 0。完整评分重算只覆盖声明的三个任务位置；logistic 使用标准库，未另行独立拟合。
- 秩是实际测得数值秩，不是有效秩：DTD 范围 109—125、均值 124.684；EuroSAT 范围 111—125、均值 124.924；理论上限 125。子空间重叠和秩都不能单独证明有益的类内干扰机制。
- 所有区间均为固定且反复暴露图像池内、按历史随机种子分层的配对任务 bootstrap；图库条件和随机控制不作为新的独立任务。新种子不等于新数据集验证。
- 本地缓存计算：角色整包 836.18 秒，方向整包 275.18 秒；这包括多个方法、加载和变换，不能解释为单方法推断耗时。
- 两域沿用不同的源域选定 gamma（五样本 DTD 为 1，EuroSAT 为 0.1）；域间收益差异并未单独隔离数据分布与收缩强度的作用。其他任务对照还保留当前任务谱，其优势不能外推为完全无需当前任务信息。
- Pets 基准契约未替换；本结果也不证明普遍 FSL 改进、跨骨干泛化或论文投稿就绪。
