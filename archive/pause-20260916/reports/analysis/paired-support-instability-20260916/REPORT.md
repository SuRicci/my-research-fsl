# 固定增强几何与支持样本波动：两组预测的诊断

## 结论

**EuroSAT 的已有几何收益与两组支持样本间更少的预测分歧同时出现，且净增益主要来自基线两头原本不一致的查询。DTD 没有可靠总收益。** 这是固定结果上的解释性分析，不是新分类实验、新算法或已验证启用条件。

两组各五样本支持集在每任务内原图互不重叠，共用25个查询。固定残差矩阵、分类头与所有旧预测保持不变。比较两组的诊断实际消耗每类十张支持标签；它不能直接作为五样本部署特征。

## 六项锁定端点

每域100个任务；先在同一查询上平均两个头，再按完整任务重采样。下表区间为本次10,000次bootstrap的名义99.1667%区间，六项共同报告。已有平均增益已公开，新状态分析事后提出、计算前固定；不是独立新样本/新域确认，也不解决重复研究选择问题。

|域|净准确率变化 pp|支持组分歧减少 pp|原不一致组贡献减原一致组贡献 pp|
|---|---|---|---|
|dtd|-0.28 [-0.90, +0.32]|+0.12 [-1.00, +1.16]|+1.20 [+0.66, +1.82]|
|eurosat|+3.68 [+2.76, +4.66]|+3.48 [+2.04, +5.00]|+1.96 [+1.04, +2.90]|

EuroSAT 三项联合条件通过；DTD 仅贡献差为正，总收益和分歧减少未确立，因此不通过。分组贡献差本身并不代表有益。

## 增益来自哪里

每项贡献均按全部任务查询位置计权，未以更有利的子组分母夸大结果。

|域|校正前/后两头分歧率|原不一致组净贡献 pp|原一致组净贡献 pp|纠错/破坏次数|
|---|---|---:|---:|---|
|dtd|10.24% / 10.12%|+0.46|-0.74|46 / 60|
|eurosat|13.84% / 10.36%|+2.82|+0.86|210 / 26|

纠错/破坏以两个分类头各自的预测为计数单位，每域5000次预测；不当作5000个独立样本。相同原图跨任务出现也不构成新样本。

EuroSAT 原不一致组贡献2.82pp，占净增益3.68pp的约76.6%，其余0.86pp来自原一致组。进一步四状态分解：原“两头正确”产生-0.40pp，原“两头同样错误”产生+1.26pp，原“分歧且一头正确”+2.42pp，原“分歧且两头都错”+0.40pp。**原一致错误也得到修正，不能把全部收益归因于消除支持样本波动。**

DTD原不一致组贡献+0.46pp，但原一致组损失-0.74pp，总和-0.28pp未确立。原“两头正确”损失-0.92pp，说明选择性纠错可以被已有正确预测的破坏抵消。所有4×4状态计数保存在summary.json与逐任务npz，没有筛选有利任务。

## 可以与不可以解释什么

可以说：在已暴露EuroSAT源任务、固定域别强度与固定矩阵下，正平均收益和两支持组分歧降低相伴，且原分歧组的任务加权贡献较大。该表述通过预先固定的六项名义区间检查。

不能说：识别了总体分类方差或偏差；降低波动因果地产生全部增益；没有标签就能判断谁对；新的五样本选择器已可用；DTD/EuroSAT差异证明了某个域属性。两域强度不同，稳定错误只指两次观察一致，不是总体主预测。

[Domingos的原始零一损失分析](https://homes.cs.washington.edu/~pedrod/papers/mlc00a.pdf)以训练集分布下的主预测定义偏差与方差；本分析不估计该主预测。因此选用“两个支持组的分歧与状态转换”名称。更多背景、无标签识别的限定构造、ATC/一致性估计与查询图权限比较见 literature/gain-identification-20260916/REPORT.md；通用非识别性构造不是本地经验无效定理或新颖贡献。
