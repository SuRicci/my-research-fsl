# 固定增强残差校正在 EuroSAT 保留收益，总协方差未能解释该收益

## 结论

在现有已暴露源图像与冻结参数下，固定25张校正原图的增强残差矩阵使 EuroSAT 平均准确率提高3.68个百分点，相对同图像预算的总协方差提高3.40个百分点。DTD 的增强残差收益未确立，而总协方差降低准确率。故“任意整组协方差都足以解释收益”不符合本次对照；同时，不能据此给出普适有效性或部署保证。

within_minus_total 表示残差减总协方差；within_gain / total_gain 表示各自减身份映射。残差相对总协方差的两种训练方向差异：DTD +3.40/+2.96 pp；EuroSAT +3.24/+3.56 pp。DTD 残差优于总协方差不等于残差本身有益，因为总协方差是更差的对照。

相对身份映射的纠错/破坏数为重复任务内的预测事件，不是唯一原图数：EuroSAT 残差两方向分别95/14和115/12，总协方差101/101和106/92；DTD 残差21/33和25/27，总协方差27/124和24/100。正平均收益仍伴随错误增加事件。

## 对照实际改变了什么

复用原有每域100个任务，每任务 R/A/B 各25张原图；R/A分别作5类5样本训练，B作每类5张评测。父实验身份映射分数未修改。原图与特征版本均有SHA256锁。

每域从既有 D 池按RGB SHA256升序固定25张原图，全域任务共用同一个矩阵；没有按任务类别选择。D池与现有全部分类原图RGB身份无交叉。每种矩阵使用相同150视图：残差逐原图中心化，总协方差全组中心化。算子均按trace归一化，保持原gamma（DTD1、EuroSAT0.1）、L2、六视图均值和自由截距ridge正则1。没有为总协方差条件额外平移分类特征。

总协方差可分为增强残差和原图均值间协方差。全矩阵改变后，方向、谱和自然秩也会改变；实际秩125与149。因此，当前结果支持本算子下分组统计的重要性，不能唯一归因于保护语义、方向、秩或谱。它也不是无正则完全白化的复现，不能泛化为所有白化方法无效。
